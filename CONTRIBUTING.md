# Contributing

This repository welcomes documentation corrections, reproducible bug reports and constructive community discussion. **It does not contain the proprietary WaveLab application source**, and contribution instructions do not grant access to that source or permission to distribute modified application builds.

## Bugs and documentation

Search existing [Issues](https://github.com/ahmedrabie-23/RBE-WaveLab/issues), then use the Bug Report or Documentation Problem template. Report factual steps and expected/observed behavior; distinguish your own observations from assumptions. For scientific discrepancies, include units, frequency, supported model/settings and an independently reproducible nonconfidential reference where possible.

Documentation pull requests should be small and explain the correction. Preserve approved product identity, scientific limits, licensing and privacy statements. Do not introduce a generic open-source license, application source, build scripts, binaries, installers, private specifications or internal test logs. Do not imply an unannounced feature, platform, timeline or release is approved.

## Ideas and learning

Use [Discussions](https://github.com/ahmedrabie-23/RBE-WaveLab/discussions) for questions, experiments and early ideas. The Feature Request template is also available for a concrete proposal. A request, vote or contribution is not a commitment to implement it. Future versions and monetization beyond V1.x are undecided.

Only submit material you are authorized to share. Use minimal examples and remove credentials, personal information and confidential engineering data. Follow the [Code of conduct](CODE_OF_CONDUCT.md). Report security concerns privately according to [SECURITY.md](SECURITY.md).

GitHub Issues and Discussions are enabled for this public community repository. Support and review remain best-effort.
